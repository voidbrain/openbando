# Camera compass

The main stage and 3D Studio use the same bottom-left compass. North uses the red danger token for a familiar navigation convention; the needle follows camera orientation and calibration. Click or Enter resets the camera to north, drag the dial to rotate, and use the arrow keys for five-degree steps. The north-up 2D plan displays a non-interactive indicator. Keep the compass clear of the docked inspector and provide a visible keyboard focus ring.
