# Archive

Dated history: closed backlog records, one file per year (`backlog-<year>.md`, in closing-date order), older evidence moved out of active records (`evidence-<year>.md`, under each record ID), the reconciliation log with the `Other changes` entries moved out of the backlog (`reconciliation-<year>.md`), the old working plan (`working-plan/`) and finished plans (`plans/`). These files preserve evidence as it was; they are not current status and do not override [AGENTS](../../AGENTS.md), the [backlog](../BACKLOG.md) or its [rules](../BACKLOG-RULES.md). Historical archives keep their original table formats.
